# Overview

AI Dubber is a professional desktop application designed to simplify AI-powered video localization.

It combines speech recognition, translation, subtitle editing, text-to-speech, and video rendering into a single workflow.

The project is open source and aims to provide a modern AI dubbing experience for creators, educators, developers, and businesses.

# Installation

Clone the repository

```bash
git clone https://github.com/meanmalis36-dot/AI-Dubber.git
```

Go to project

```bash
cd AI-Dubber
```

Install requirements

```bash
pip install -r requirements.txt
```

Run

```bash
python src/main.py
```

# Why AI Dubber?

AI Dubber is designed to reduce the complexity of multilingual video production.

Instead of using multiple software tools, users can translate, dub, generate subtitles, and export videos from one application.
